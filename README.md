### <u>**Non-Negative Matrix Factorization Using Non-Von Neumann Computers (Code)**</u>

This is the code for the experiments done in our paper titled "Non-Negative Matrix Factorization Using Non-Von Neumann Computers"

Files and what they do:
*   `gen_matrices.ipynb` was Used to generate all the test cases for our paper.
*   `integer_nmf_ortools.py`, `nmf.py` and `nmf_qubo.py` are files that host the core classes and functions used in the experiments.
*    `_script.py` files are the python scripts for all the four experiments in our work.
*    `plot_...ipynb` files are jupyter notebooks that produced the graphs.

Python and Package version:
* Python 3.11.4
* Scikit-learn 1.3.1
* Or-Tools 9.14.6206
* qci_client 4.5.0
